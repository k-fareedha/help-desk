# AI Context Management and Compaction

## Context strategy
1. Give AI agents AGENTS.md, ARCHITECTURE.md, and the exact files relevant to the task.
2. Keep requests scoped to one feature or bug.
3. After a large discussion, write a short summary of decisions, modified files, known bugs, and next steps here.
4. Start a fresh chat with that summary when context grows large; do not assume the model remembers earlier chats.
5. Preserve critical decisions in git commits and markdown, not only chat history.
